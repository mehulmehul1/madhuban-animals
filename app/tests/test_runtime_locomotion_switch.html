🧪 Test: Runtime Locomotion Switch

Purpose: Verify builder can switch active locomotion by ID at runtime and quadruped gait hotkeys work.

Controls:

  • D — Toggle debug panel
  • 3 — Build Horse (quadruped)
  • 4 — Build Lizard (sprawling quadruped)
  • W/T/G/P — Walk/Trot/Gallop/Pace (when quadruped gait is active)
  • L — Cycle locomotion for current creature
  • O — Toggle automatic gait switching (if supported)

Expected:

  • Pressing L cycles: Horse → quadruped-walk → sprawling-quadruped; Lizard → sprawling-quadruped → quadruped-walk.
  • W/T/G/P trigger gait transitions when a quadruped gait is active.
